# Day 55: Full Adder and Full Subtractor Using DEMUX

## Introduction
This project demonstrates the implementation of a Full Adder and a Full Subtractor using a Demultiplexer (DEMUX) with Verilog HDL.

## Objectives
- Understand the working of a Full Adder and Full Subtractor.
- Implement arithmetic logic functions using DEMUX.
- Practice Verilog RTL design and simulation using Xilinx Vivado.

## Design
**Full Adder**
- Inputs: A, B, Cin
- Outputs: Sum, Carry

**Full Subtractor**
- Inputs: A, B, Bin
- Outputs: Difference, Borrow

## Tools Used
- Verilog HDL
- Xilinx Vivado

## Verification
The designs can be verified using testbenches by applying all possible input combinations and checking the output waveforms.

## Observation
The Full Adder and Full Subtractor outputs depend on the input combinations. DEMUX outputs can be combined to implement the required arithmetic functions.

## Learning Outcome
Learned how to implement and verify full arithmetic circuits using DEMUX-based logic in Verilog HDL.
